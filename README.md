# dsh-harmonyos

DeepSeek Harness 纯血鸿蒙插件：在对话中构建、运行鸿蒙应用，实时查看设备画面并与设备交互，完全通过 HDC 驱动。

当前开发状态：已完成 DSH 插件骨架、HDC 设备发现、截图、预览会话和基础交互工具。

当前工具：`harmony_devices`、`harmony_preview_start`、`harmony_preview_stop`、`harmony_preview_info`、`harmony_screenshot`、`harmony_interact`。

## 开发

```powershell
pnpm install
pnpm run typecheck
pnpm run build
pnpm test
```
